# M14 — The demo · **PASS**

**Gate:** `npm run gate -- M14` (standing gate, M14 rules, M14 browser walkthrough). 837/837
unit tests.

## What exists (`projects/demo`)

vdd's demo, ported to Angular: the same 16 panel kinds, the same six locales and eight skins,
and the same shell. Run it with `npm run demo`.

- **Shell (`app.ts`).**
  - A top bar with sidebar, toolbar, taskbar, skin, locale, animation and colour-scheme controls.
  - `<ndd-sidebar>` wraps `<ndd-secondary-sidebar>`, which wraps `<ndd-desktop>`. Both sidebars
    are bound with `[(activeTabId)]` and `[(visible)]`.
  - `<ndd-toolbar>` is placed on any of the four edges.
  - The four hosts sit at the bottom of the template.
  - The toolbar items and sidebar tabs come from `injectMergedToolbarItems` and
    `injectMergedSidebarTabs`, so panels contribute to them.
  - Choosing a locale also sets its reading direction; العربية switches the workspace to RTL.
- **Bootstrap (`main.ts`).**
  - `provideDockableDesktop({ formatMessage, panels })`, zoneless.
  - `?zone` boots the same app on zone.js, which is how the walkthrough runs under both
    schedulers.
  - The four heavy panels (the code editor, the markdown editor and both maps) are
    `loadComponent`, so Monaco, Leaflet and the markdown pipeline stay out of the initial
    bundle: 515 kB raw, 118 kB transferred.
- **Panels.** Each vdd panel is now a signal-based standalone component.
  - **Control Center** drives the whole API. **Code Editor** is Monaco with a panel context
    menu. **Markdown** is Monaco plus a `unified` preview, a divider built on
    `startPointerDrag`, six contributed toolbar actions and a contributed table of contents.
  - **Main Map** is Leaflet with a panel overlay: a panel toolbar, a corner-docked legend, a
    `stretch: 'width'` status strip, and camera widgets opened from data through
    `injectFloatingWidgets()`. **Leaflet Map**, **Layers** and **Tools** exercise the event bus,
    `injectToolbar()`, `injectSidebar()` and contributions.
  - **Terminal**, **Preview** and **Timeline** are counters that prove zero unmount. **Intercept
    Form** covers dirty state, the close guard, the live title and force close. **Notes**
    covers dirty state and `onSaveState`, restored through a `content` input and
    `linkedSignal`.
  - **Assets**, **Help**, **Locator** and **RTL** complete the set. The Panel manager form
    opens in a drawer, a modal or a sidebar tab.
- **Third-party integration without wrappers.** Monaco runs through a 60-line `monacoEditor()`
  helper that creates the editor after render, disposes it with the component, and syncs a
  `WritableSignal` both ways with undoable edits. Leaflet is created outside Angular, so a pan
  costs no change detection. Neither needs an Angular wrapper library.
- **Icons** are CSS-mask classes (`dd-icon dd-icon-<name>`), because a class string is one of
  the three forms of `NddIcon`. The Tools panel's glyphs and the markdown actions are classes
  too.

## M14 rules (`scripts/gates/m14.mjs`)

1. **The demo is a CLI application built by the standing gate.** It takes the library
   stylesheet from the built package, as a consumer does, and loads the Leaflet and KaTeX CSS.
2. **No demo leak.** No `dd-` class appears in the library stylesheet, the library package
   never mentions the demo, and the demo's CSS defines only `dd-` classes and dependencies'
   classes. Any `ndd-` selector must sit under a `dd-` ancestor.
3. **The library is used by package name,** never by path. `main.ts` uses
   `provideDockableDesktop` and `loadComponent`.
4. **34 capabilities, each *called* or *bound* in code.** Comments are stripped first, so prose
   cannot satisfy a rule.
5. **No object literal is bound to a `placement` model,** in the demo or in the library.
6. **Stylesheet hookups.** Every `[data-*]` the stylesheet keys on is emitted, and no token is
   declared only in a colour-scheme block.
7. **Dependencies.** ADR 0012's demo dependencies are present and there are no framework
   wrappers. The library has **no runtime dependencies**: `tslib` was removed, since the bundle
   never imported it. The built FESM imports nothing but `@angular/core` and `@angular/common`.

## Findings

1. **A library defect: `PanelRef` actions called from an `effect()` looped forever.**
   - `effect(() => panel.setTitle(...))` and `effect(() => panel.setDirty(...))` are the
     documented forms. Each action read state on its way in, and read it tracked: `isKnown()`
     reads `workspace.state()`, and the overlay host's context reads `instance()`.
   - So the calling effect depended on the very state its call changed. `setPanel` also wrote a
     fresh record even when nothing had changed, so the effect re-ran without end. In the demo,
     opening the Terminal froze the page.
   - M10's `trackDirty` had escaped only because it wraps its own call in `untracked`, and no
     unit test used the plain-effect form.
   - **Fix:**
     - every `PanelRef` action runs `untracked`, like the workspace's own actions;
     - `updatePanelTitle` and `setPanelDirty` do nothing when the value is unchanged.
   - **Pinned** by three new tests in `panel-lifecycle.spec.ts`: the docked form, the modal form
     and idempotency.
   - **Mutation:** restoring the tracked reads fails two of them with
     `NG0103: Infinite change detection`.
2. **The walkthrough could hang silently.** `page.evaluate` has no timeout, so a page stuck in a
   loop stopped the gate with no output. Each evaluate now fails its step after 20 seconds.
3. **Monaco's worker entries go through its exports map** (`monaco-editor/editor/editor.worker.js`,
   not `esm/vs/…`), as vdd found too.
4. **`[innerHTML]` would strip the maths.**
   - Angular's sanitiser removes KaTeX's inline styles and MathML.
   - The preview trusts the pipeline's output explicitly, and a comment says when not to do
     that. vdd's `v-html` and rdd's renderer give the same trust.
   - The walkthrough asserts that KaTeX actually rendered.
5. **The demo's initial-bundle warning budget is 600 kB**, raised from the CLI starter's 500 kB.
   The error budget is still 1 MB. Leaflet and `extend` are declared CommonJS dependencies.
