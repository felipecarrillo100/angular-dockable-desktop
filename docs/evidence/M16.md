# M16 — Skin branding (1.1.0) · **PASS**

**Gate:** `npm run gate -- M16` (standing gate, M16 rules, M16 browser gate): PASS, 844/844 unit
tests across 34 files. `npm run gate:selftest`: 33 cases, every violation rejected.

## What changed

react-dockable-desktop 7.2.0's skin branding, ported ([ADR 0014](../decisions/0014-brand-variables.md)):

- `styles.css`: 14 `--ndd-accent-color` declarations read `var(--ndd-brand-accent, <skin colour>)`
  (13 converted, 1 new in `[data-color-scheme="light"]`, `#0066cc`); 142 declaration lines of
  accent tints and stale accent-family literals became `var(--ndd-accent-color)` or
  `color-mix(in srgb, var(--ndd-accent-color) N%, transparent)`; 2 on-accent rules read
  `--ndd-brand-on-accent`; `:root` declares `--ndd-font-family: var(--ndd-skin-font-family, …)`,
  six skins set `--ndd-skin-font-family`, and the five chrome font rules lost their private
  fallbacks. The conversion is textually identical to rdd 7.2.0's after the prefix.
- Playground: `?cs=light`, `?ba=` / `?bon=`, `?anim=0`, `NddConfirm` exposed.
- Docs: theming chapter (Brand your app, Skin fonts, brandable skins, token reference), chapter 1,
  chapter 12, README (and the package README), CHANGELOG 1.1.0, ADR 0014, PARITY.md. Version 1.1.0.
