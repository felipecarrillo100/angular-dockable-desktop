diff directly failed 25 of 67 hunks.

  drop preview on the accent. The unregistered-panel message keeps its literal danger red.

  re-run green after the move). Playground: `?bs=`, `?bt=`, `?rs=`.
- **M16's 1.1.0 version pin** replaced by ADR 0015's rule (the current version has its own
  CHANGELOG entry), recorded in ADR 0016.
- Docs: theming chapter (Your surfaces, Corners, the fourth habit, token rows, and the internal
  derived names, which M15/M16's token check requires of everything `:root` declares), README and
  package README, CHANGELOG 1.2.0, ADR 0016, PARITY.md, plan. Version 1.2.0.
