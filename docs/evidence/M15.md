**Gate:** `rm -rf node_modules dist && npm ci`, then `npm run gate -- M15` (standing gate, M15
rules including every earlier browser gate, M15 browser gate). 839/839 unit tests.
`npm run gate:selftest`: 33 cases, every violation rejected.

## What exists

- **`README.md`**: install, a quick start that is byte-for-byte the code the consumer smoke
  proves, features, documentation, development and CI. The package README is generated from it
  (`scripts/sync-package-readme.mjs`) with absolute links, and ships in the package.
- **The manual**, `docs/manual/`: 13 chapters (about 4,200 lines) and an index, adapted from vdd's
  and checked against ndd's shipped API. It includes the migration guide from rdd and vdd
  (chapter 12), a token reference for all 125 `--ndd-*` tokens (chapter 10), and an API
  reference naming all 147 exports and types (chapter 13).
- **`CHANGELOG.md`**, entry 1.0.0, with the parity line vdd 1.1.1 / rdd 6.3.1. The package
  version and `VERSION` are both `1.0.0`.
- **`LICENSE`**: MIT, and it ships in the package.
- **ADRs:** 0012 (the demo's scope) and 0013 (every action is untracked). The index now lists
  0011–0013.
- **CI:** `.github/workflows/gate.yml` runs the release gate, and `pages.yml` publishes the demo.
  Both use Node 24, which is inside Angular's engine range. They are written but not run, since
  there is no remote (ADR 0010).

   - theming's tokens match the stylesheet's `:root` tokens in both directions.

## Browser gate — N15

Dragging a split divider 100 px right moves it exactly 100 px, in LTR and in RTL, under both
schedulers. The control asserts vdd's behaviour (−100 px under RTL) and is rejected.

## Findings

Writing the manual against the source found real defects. Each is fixed, and each is pinned by a
test or gate that fails when the fix is reverted.

1. **The effect loop also affected `toast()`** (ADR 0013). A toast with an id, called from an
   effect, read the queue tracked and re-ran forever.
   - The queue is now read untracked, and so is a contribution's withdraw.
   - Pinned by a bounded test in the toast spec. With the fix reverted it fails rather than
     hanging: the first unbounded version hung the suite, so the test's effect now stops after
     20 runs.
2. **N15: a split divider moved away from the pointer under RTL.** Inherited from vdd. The drag
   now reads the row's computed direction. Pinned by the M15 browser gate and its control.
3. **N16: `ToastAdapter.show` was never called.** Inherited from vdd. vdd's own test ("an adapter
   receives every call") stubbed `show` and never asserted it; the ported test now does.
4. **N17: a custom context-menu template was dismissed on `pointerdown`, before its own click.**
   Inherited from vdd. The menu host now counts as inside. Pinned by a new context-menu test;
   reverting the fix fails it.
5. **`--ndd-font-family` did not reach the workspace.** Four rules hard-coded their font stacks.
   They now read the token and keep their own stack as the fallback, so nothing changes by
   default.
6. **Smaller fixes:**
   - three source comments cited ADR 0009 for layout compatibility; it is 0008;
   - the `canClose` comment on a leaf was misleading;
   - PARITY §1 misstated `usePanelContextMenu`'s shape;
   - §4.3 now records `open()` returning an `NddModalRef`.
7. **Recorded as known gaps** (PARITY §5), shared with vdd:
   - three English-only accessible names;
   - `loadLayout` accepting a partial payload.
