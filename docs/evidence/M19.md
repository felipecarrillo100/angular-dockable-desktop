# M19 — Pop-out windows (1.12.0) · **PASS**

**Gate:** `npm run gate -- M19` (standing gate, M19 rules, M19 browser gate): PASS, 1442/1442 unit
tests across 57 files; api-surface 62 runtime + 110 types; docs-api 165 code blocks. The M19
