## rdd 7.12.2 follow-up: the title icon's size (2026-11-23)

MapEvolution's report on the 1.12.0 tgz: a pop-out frame's title icon had no size, so their
`mat-icon` (width/height auto) grew the header to 309 px. The fix sizes `.ndd-popout-frame__icon` as
a floating window's (14 × 14) and draws an `svg`/`img` in either box at 14 × 14, as a tab's icon slot
does. rdd's third rule, a cap scaling a bigger element down to its box, isn't ported: it would reach
`<ndd-icon>`, not the app's element (ADR 0019). M19's new `title icon` case, zoneless and with
`?zone`. Mutations of the built playground's stylesheet, each run with `M19_CASES=titleIcon,wrapper`,
each caught:

| Mutation | Caught by |
|---|---|
| the frame icon back to `display: inline-flex` only | title icon: box 0 × 0, icon 0 × 0, the widget frame's box 16 × 16 |
| no `svg`/`img` rule on the frame icon | title icon: the unsized icon 0 × 0 |
| no `svg`/`img` rule on the floating window's icon | title icon: the unsized icon 0 × 13 in a floating title |
