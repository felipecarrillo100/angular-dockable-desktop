M13 browser gate). 834/834 unit tests against vdd's 765.

before it.

## Findings

1. **N4, the tab close button.**
   - axe reported *nested interactive controls*: the × was a button inside a `role="tab"`.
   - The × is now `aria-hidden` and pointer-only. Delete on the focused tab closes it,
     announced through `aria-keyshortcuts`, which is the WAI-ARIA tabs pattern's own
     recommendation.
   - The locale test now reads the ×'s `title`.
2. **N13, the toolbar flyout.** Its items used `aria-pressed` inside a menu, which is not an
   allowed state there. They are now `role="menuitemradio"` with `aria-checked`.
3. **N14, the toasts.** The container carried an `aria-label` on a generic element, which axe
   forbids. It is now a labelled `role="region"`.
4. **Tab-bar hover ticked once per move.** A `(pointermove)` template listener on each tab
   costs one application tick per event: 40 ticks for 40 moves over an idle tab bar. It is now a
   single listener delegated through the tab bar and registered outside Angular: 0 ticks.
5. **Coexistence.**
   - Framework typography and resets reached the chrome: Bootstrap's `line-height: 1.5` and
     button margins, Tailwind's preflight `padding: 0` and `display: block` SVGs, and Material's
     typography.
   - A "coexistence base" block in the stylesheet now fixes it. It gives chrome roots their own
     font, `line-height`, colour and letter-spacing. Library buttons get `font: inherit`,
     `padding: 0` and `margin: 0`, titles get `line-height: 1.3`, and SVGs directly inside
     library buttons are `display: block`.
   - The rules are all scoped to `ndd-` DOM (D8), so the host page is still untouched.
6. **N12, SSR.** `panel-dom` wrote `el.dataset.nddPanel`, and Domino, the server DOM, has no
   `dataset`, so a server render crashed. It now uses `setAttribute('data-ndd-panel', id)`.
   Only the consumer smoke could find this; jsdom has `dataset`.
7. **N11, `ndd-fill-viewport`.** The utility lost on specificity to `.ndd-workspace`'s own
   `height`, so a consumer's full-viewport desktop rendered at 0px. The selector now includes
   `.ndd-workspace.ndd-fill-viewport`.
8. **Dead rules removed:** `.ndd-panel-port` and `.ndd-cursor-move`, which were inherited from
   vdd's stylesheet with no emitter in either library. The static sweep found them.
9. **Consumer-gate harness fixes.** These concern the harness, not the library.
   - `ng new` refuses to run inside an existing workspace, and `--directory` may not escape the
     working directory. So a local CLI in the scratchpad generates the app next to itself, and
     the app is then copied under `artifacts/consumer/`.
   - The build log is failed on any `ERROR`.
   - The server is run with `NG_ALLOWED_HOSTS=localhost`, which Angular 22's SSR host check
     requires.
