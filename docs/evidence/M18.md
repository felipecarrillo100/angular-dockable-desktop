**Gate:** `npm run gate -- M18` (standing gate, M18 rules, M18 browser gate): PASS, 857/857 unit
tests across 35 files. `npm run gate:selftest`: 33 cases, every violation rejected.

## What changed

react-dockable-desktop 7.4.0's fixes from a consumer's field report, ported ([ADR 0017](../decisions/0017-frost-on-a-pseudo-element.md)),
by the same transform vue-dockable-desktop 1.5.0 used:

- **Frost on `::before`, reduced motion and title functions:** the same as in vdd.
- **Direction:** `<ndd-sidebar>`, `<ndd-secondary-sidebar>` and `<ndd-toasts>` follow `setDirection('rtl')`, and so does everything inside a sidebar.
- **Non-finite saved geometry is repaired** in `core/serialize.ts`.
- **The CHANGELOG ships in the package.** `scripts/sync-package-readme.mjs` copies it into the library project, since ng-packagr won't read assets from outside it, and M18 fails on drift.
- **Docs:** the `provideWorkspaceDirectionality()` recipe for Angular Material and CDK users (type-checked against the installed CDK 22), plus the theming and i18n chapters, CHANGELOG 1.3.0, ADR 0017, PARITY.md and the plan's M18. Version 1.3.0.
