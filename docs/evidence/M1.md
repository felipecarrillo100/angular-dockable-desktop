- `build:lib`, `types:spec`, `lint`, `unit`, `counts`, `css-prefix`, `api-surface`,
  `docs-api`;

## What exists

- **Angular CLI 22.2 workspace** (`ng new --no-create-application`). The library came from
  `ng generate library --prefix ndd`, and the `playground` (`pg-`) and `demo` (`dd-`) apps
  from `ng generate application`. The apps consume the **built** package (`paths` →
  `dist/`), exactly as a user would.
- **Library package:**
  - peers `@angular/core` and `@angular/common` `^22.0.0`, and `tslib` only;
  - `sideEffects: ["**/*.css"]`, with `styles.css` shipped through ng-packagr `assets` and
    exported as `angular-dockable-desktop/styles.css`;
  - FESM2022 + bundled types.
- **Strictness:** `strict`, `strictTemplates`, `strictStandalone`, and extended diagnostics as
  errors. TypeScript is pinned `~6.0`.
- **Tests:** Vitest through `@angular/build:unit-test` with jsdom. Specs live in
  `projects/angular-dockable-desktop/test/`, outside `src/`, so test helpers can never be
  packaged. Finding: the builder resolves `include` against `sourceRoot`, so the pattern is
  `../test/**/*.spec.ts`.
- **Lint:** angular-eslint (recommended plus template accessibility), with selector prefixes
  `ndd` (library), `pg` and `dd` (apps).
- **Gates** (`scripts/gate.mjs`, `scripts/gates/`):

  | Rule | What it checks |
  |---|---|
  | `counts` | monotonic floors, vdd floors per `test/port-map.json`, no skips, no failures |
  | `css-prefix` | classes, properties, keyframes and animation references in the stylesheet; every class a component emits (templates, host metadata, `classList`, Renderer2); D6 selector anchoring |
  | `api-surface` | runtime and type exports of the **built** bundle against `api-surface.json`, refusing a stale build |
  | `docs-api` | doc imports and `<ndd-*>` elements must exist |
  | `zone` | the playground boots under zoneless and zone.js, with no console errors |

- **Browser harness** (`lib/browser.mjs`): every browser gate runs its scenario under both
  schedulers against the production build.
- **Port map:** all 33 vdd suites (765 tests) mapped to ndd specs, each with the milestone it
  is due.
- **ADRs** 0001, 0003–0010 written from plan Part A; 0002 from M0.

## Selftest

`npm run gate:selftest` seeds a violation for each rule and requires rejection: 29 cases, and
every violation is rejected for the stated reason (checked with `-v`). Examples:
- an unprefixed class inside `@media`;
- `animation: fadeIn`;
- `body {}` (D6);
- a component emitting `[class.active]`;
- a stale build;
- a doc importing `WorkspaceClient`.
