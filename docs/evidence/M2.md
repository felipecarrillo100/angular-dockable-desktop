## Findings

1. **An unscoped `[data-color-scheme="light"]` token block** was flagged by the D6 rule on
   first contact. It is the family's documented light-mode contract, and it declares only
   `--ndd-*` tokens (95 + 6, checked). The rule was refined by **ADR 0011** (unscoped
   selectors may carry only `--ndd-*` tokens), made separately from any implementation
   change, and the selftest gained two cases.
2. **The CLI's `noPropertyAccessFromIndexSignature`** rejected 23 dot-accesses in verbatim
   code and specs. Kept, because it is what an Angular user's project has; the accesses were
   converted mechanically from compiler positions. M2 rule 6 pins the strict flags so they
   cannot be loosened later.
3. **`build:lib` type-checks only what `public-api.ts` reaches.** Unexported modules are
   covered by `types:spec` and the unit build, which does type-check.
